## 2. 评审检查清单（每轮均逐项核对）

- [ ] 实现与 `design.md` 接口契约一致（参数、返回类型、异常语义）
- [ ] 验收标准（`tasks.md`）在测试中有对应用例，且测试先于实现
- [ ] 命名符合团队规范（模块/函数/变量语义清晰，无缩写歧义）
- [ ] 无硬编码密钥、令牌；敏感配置全部走环境变量
- [ ] SQL 使用参数化查询，日志不打印令牌与个人信息
- [ ] 异常处理不吞错，错误信息可定位
- [ ] 提交粒度 = 一个可验证交付物，提交信息符合 `feat|fix|test|docs: [任务编号]`
- [ ] 静态扫描（ruff / flake8）零告警
