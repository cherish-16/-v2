## 1. 变更单原文

> **需求变更单 CR-2026-11-25-01**
>
> **变更主题**：新增飞书考勤数据采集模块
>
> **背景**：团队希望日报不仅反映「做了什么」，也反映「到岗情况」，便于组长核对出勤。
>
> **变更内容**：
> 1. 采集飞书考勤数据（出勤 / 缺勤 / 迟到 / 请假）。
> 2. 考勤记录纳入个人日报与团队日报，作为独立来源条目。
> 3. 条目必须可追溯至原始考勤记录。
>
> **约束**：不得影响既有 GitHub / 飞书任务 / 飞书消息三条采集路径的行为。
>
> **对应教材**：《SDD 实战》第 7.5 节 v1.1 场景。
