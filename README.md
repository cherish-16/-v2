## 提交信息约定

采用 [Conventional Commits](https://www.conventionalcommits.org/zh-hans/)：

```
<类型>(<范围>): <描述>
```

常用类型：`feat` 新功能、`fix` 修复、`docs` 文档、`style` 格式、`refactor` 重构、`test` 测试、`chore` 构建/工具。
